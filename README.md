## 🚀 Featured Projects

### 🌍 [HappiScope AI – Global Happiness Intelligence](https://github.com/sandeepundurthi)
> End-to-end analytics & ML platform on 2005–2025 World Happiness data across 150+ countries

- 📊 Built an **XGBoost model** achieving **R² = 0.91** on happiness score prediction
- 🔍 Applied **SHAP** for explainability and key driver analysis
- 🗺️ Deployed an interactive **Dash dashboard** with rankings, country comparisons, and scenario forecasting
- `Python` `Pandas` `XGBoost` `SHAP` `Dash` `Plotly`

---

### 📦 [SupplyChain IQ – End-to-End Logistics Data Engineering Pipeline](https://github.com/sandeepundurthi)
> Automated logistics analytics platform processing shipment, warehouse, and inventory data

- ⚙️ Designed **ETL workflows** and **PostgreSQL** data models from scratch
- 🔔 Identified delivery delays, warehouse bottlenecks, and low-stock risks at scale
- 📱 Delivered operational insights via an interactive **Streamlit** dashboard
- `Python` `PostgreSQL` `SQL` `ETL` `Streamlit` `Pandas` `Makefile`

---

### 🥦 [Food Desert & Public Health Risk Dashboard](https://github.com/sandeepundurthi)
> Interactive analytics dashboard identifying U.S. counties at elevated public-health risk

- 🏥 Analyzed relationships between food access, poverty, obesity, diabetes, and inactivity
- 📍 Sourced and integrated **USDA** and **CDC** datasets for cross-indicator insights
- 📊 Built county-level risk visualizations using **Plotly** and **Streamlit**
- `Python` `Pandas` `Streamlit` `Plotly` `Seaborn` `Matplotlib`

---

### ⚡ [ChargeWise AI – EV Infrastructure Gap Forecasting Platform](https://github.com/sandeepundurthi)
> End-to-end analytics system for identifying underserved EV charging regions

- 🗺️ Analyzed EV population vs. public charger data to surface infrastructure gaps
- 📈 Applied **forecasting** and gap scoring to prioritize counties for expansion
- 🔋 Delivered county-level recommendations through an interactive **Streamlit** dashboard
- `Python` `Pandas` `Scikit-learn` `Plotly` `Streamlit` `SQL`

---

### 📉 [Corporate Layoff Intelligence Platform](https://github.com/sandeepundurthi)
> Executive-style workforce analytics platform analyzing global layoff trends

- 💼 Analyzed industry instability, funding-stage risk, and geographic workforce impacts
- 📊 Built an interactive platform with drill-down views across sectors and geographies
- 🧠 Powered by real-world economic datasets with clean, production-grade code
- `Python` `Pandas` `NumPy` `Plotly` `Streamlit` `Jupyter`
